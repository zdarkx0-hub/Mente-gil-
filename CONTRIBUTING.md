# Como contribuir

Obrigado por ajudar a melhorar o Mente Ágil.

## Antes de começar

- para erros, abra uma issue usando o formulário de bug;
- para ideias, use o formulário de nova funcionalidade;
- vulnerabilidades não devem ser publicadas em issues: siga [SECURITY.md](SECURITY.md).

## Enviando uma mudança

1. Crie uma branch a partir de `main`.
2. Mantenha a alteração focada em um único objetivo.
3. Siga a organização descrita em [docs/ARQUITETURA.md](docs/ARQUITETURA.md).
4. Atualize testes e documentação quando necessário.
5. Execute `npm run check`.
6. Abra um Pull Request e preencha o checklist.

Commits devem explicar o resultado da mudança, por exemplo: `Organize study components by responsibility`.
